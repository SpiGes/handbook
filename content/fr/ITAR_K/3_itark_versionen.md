|Version|Description|Langue|
|---------|---------|---------|
|Version automatique|Remplie avec les données SpiGes collectées. Les valeurs qui ne sont pas disponibles dans SpiGes sont affichées en lila.|Un fichier avec changement de langue dans le menu (depuis la V.17)|
|Version provisoire|Complétée par les données modifiées et complétées manuellement dans les cellules lila lors du rechargement (re-upload dans SpiGes).|Un fichier avec changement de langue dans le menu (depuis la V.17)|
|Version finale et signée|Dernière version provisoire, qui ne peut être créée qu'après la fin du relevé SpiGes (après clôture). Celle-ci ne peut plus être changée.|Reçue en 1 langue (celle du re-upload), 2 fichiers|

{{</markdown>}}

Pour la version finale, la langue dans laquelle la version automatique complétée a été rechargée fait foi.
